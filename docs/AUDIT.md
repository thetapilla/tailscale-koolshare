# 审计与验证记录

基线：Koolshare rogsoft `1b82ebb805697e8c22f4ceb4bce62cb8de58424a`。

## 已处理的插件缺陷

| 范围 | 原版可见行为 | 3.0.0 处理 |
|---|---|---|
| 构建 | tar 生成后才更新包内版本；多个平台共用输出 | staging 先写版本，每平台独立产物及可重复归档 |
| 安装 | 先删除旧文件，复制失败仍可能打印完成 | 文件预检、同文件系统 staging、备份、失败恢复、成功后注册 |
| 核心升级 | 插件升级覆盖核心，核心没有独立生命周期 | 核心版本目录和 current/previous 指针，保留已有核心 |
| 状态页面 | 重复 ID、HTML 拼接、同步初始化 | 唯一 ID、文本渲染、异步请求与超时 |
| 任务协议 | 固定日志与结束字符串，无法关联并发操作 | 数字任务 ID、结构化终态和全局互斥 |
| 轮询 | empty、挂起请求或错误会终止刷新 | 有界请求、退避、单请求在途、空结果继续刷新 |
| 网络规则 | 现场存在重复放行及 MASQUERADE | 独立规则链、重复执行幂等，保留 Fullcone 优先级；授权后同步地址，繁忙时排队重放NAT事件 |
| 授权与恢复 | 非结构化 waiting 文案 | LocalAPI 状态与健康原因，授权/手动停用豁免 |

原版五套后台入口为 ELF，公开分支和已查目录提交历史中没有可复用的后台 Shell 源码。3.0.0 按已验证接口重新实现；没有把不可读内部逻辑当作已经完成逐行审计。

## 长期离线问题的证据边界

只读现场检查时，Tailscale 1.94.2 的本地 API 为 Running、控制连接在线且没有当前健康告警。现存日志未保留发生长期离线时的完整现场；用户反馈重启插件能恢复。已观察到启动记录和防火墙规则重复，但尚无证据证明这是长期离线的唯一或直接根因。

3.0.0 消除已知并发/重复规则问题，并增加恢复前的诊断记录与有界自动恢复。不能仅凭 Docker 测试宣称原始长期故障已被定位或消除。

## 验证层次

- Go 测试：签名、清单、哈希、架构、路径穿越/链接拒绝、超时、LocalAPI 脱敏、原子指针及日志上限。
- 脚本模拟：身份保留、操作锁、PID 所有权、看门狗阈值、更新阶段中断、自动/手动回滚、安装失败恢复。
- 前端测试：异步超时、任务关联、失去 ACK 后仅查询、重复 ID、恶意文本及按钮状态恢复。
- Docker：BusyBox 1.25.1 ash、ARM32/ARM64 真实核心启动及 LocalAPI、确定性打包和六包内容一致性。
- 实机待验：厂商防火墙、Fullcone 共存、真实子网/出口流量、NAT 重建及21天持续运行。见验收清单。
