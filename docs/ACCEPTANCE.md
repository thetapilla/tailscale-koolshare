# 实机验收清单

本次开发在本机与 Docker 完成。部署前保存原安装包及必要配置备份，并确保存在独立于 Tailscale 的管理路径。实际路由器修改由设备所有者执行。

## 安装与身份

1. RT-AX86U Pro / RT-BE86U 选择 HND 包，或使用通用包；记录具体固件、软件中心、内核及剩余空间。
2. 软件中心离线安装后确认插件版本3.0.0；迁移安装应保留原核心版本、六项配置和原设备身份。
3. 全新安装首次启用时完成授权；关闭后不应被看门狗重新拉起。
4. 分别用通用包和对应平台包验证安装结果，仅保留本机架构程序。

## 网络与升级

1. 检查节点互访、LAN到远端子网、远端到本地LAN、路由器管理访问以及出口节点。
2. 验证 IPv4/IPv6 选项对外层 UDP 连接的限制；记录仍经 DERP 中继的情况。
3. 在可控维护窗口重复启动、WAN重拨和NAT重建，确认规则不增长、Fullcone仍工作。
4. 点击核心检查/更新，确认实际版本改变而插件版本保持3.0.0，设备无需重新注册。
5. 手动回滚并验证当前身份及配置继续使用；更新中断场景只在具有本地恢复手段的测试设备进行。

## 持续运行

连续观察21天。记录第一次异常的时间、核心版本、页面状态、诊断摘要和恢复记录。正常网络波动、授权等待、明确停用期间不应反复重启；恢复频率不得超过30分钟一次或24小时两次。

若再次出现管理面板离线，在手动重启前导出诊断。该记录用于区分控制连接、进程、本地 API、WAN/DNS、资源和规则问题。
